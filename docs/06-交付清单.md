## 三、构建与安装

```bash
cd ~/Desktop/DSH/仪表助理
./tools/build.sh all         # overlay + assist
cp src/clusterlab/build/clusterlab.apk apk/ClusterHUD-1.0-v4.9.8.apk
cp src/assist/build/assist.apk        apk/ClusterAssist-1.0-v4.9.8.apk

adb connect 192.168.46.1:5555     # 车机 IP 会变，见 docs/01
adb install -r apk/ClusterHUD-1.0-v4.9.8.apk
adb install -r apk/ClusterAssist-1.0-v4.9.8.apk
```

## 四、自愈判据（v4.9.8）

- 每 3 秒查一次 `dumpsys window windows` 里我们那扇窗是否 `isVisible=true`；
- 连续两次看不见（约 6 秒）→ `am start-activity --display 1 -n com.byd.clusterlab/.CardActivity`；
- 冷启动前 25 秒不检查；不搬任务栈、不按布局判据、不设「谁盖住就不抢」的例外。
