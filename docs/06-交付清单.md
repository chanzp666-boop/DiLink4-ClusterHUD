## 四、自愈判据（v5.0：三层）

1. **`:keep` 前台进程**（3 秒一轮）：`dumpsys window windows` 里该窗口 `isVisible=true` 的计数为 0 → `am start-activity --display 1`。判据只认可见性，心跳新鲜不等于看得见。
2. **shell 看门狗**（`/data/local/tmp/clusterlab-watchdog.sh`，5 秒一轮，UID 2000）：进程不在 → 发 `com.byd.clusterlab.TICK`（带 `-f 0x20`，否则停在 stopped 态的包收不到）；进程在但窗口不可见 → `am start-activity --display 1`。熄火休眠只冻结它、不清理它。
3. **精确闹钟链**：卡片在 120 秒、卡片丢 15 秒，`setExactAndAllowWhileIdle` 单次链（每次 TICK 先排下一次）。

停用：`touch /sdcard/clusterlab_halt` 后三层全部让路（看门狗与 KeepAlive 首行检查该文件）。
