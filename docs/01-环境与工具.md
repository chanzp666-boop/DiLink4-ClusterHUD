> 全部为本地离线工具链，**没有 Gradle、没有 Android Studio 构建**，`build.sh` 一条命令出 APK。
> 换机器时先核对本页版本号，不匹配会出 `aapt2` / `d8` 的各种古怪错误。

## 二、工具链（版本必须对齐）

| 工具 | 路径 | 版本 |
|---|---|---|
| JDK | `/Library/Java/JavaVirtualMachines/zulu-8.jdk/Contents/Home` | **Zulu 1.8.0_422** |
| Android SDK | `~/Library/Android/sdk` | — |
| build-tools | `~/Library/Android/sdk/build-tools/33.0.1` | 33.0.1（aapt2 / d8 / zipalign / apksigner） |
| 编译用 platform | `~/Library/Android/sdk/platforms/android-34/android.jar` | android-34 |
| minSdk / targetSdk | manifest 里写死 | 29 / 29 |
| zip | 系统自带 | 任意 |

**为什么 JDK 一定要 8**：`javac -source 8 -target 8 -bootclasspath <android-34>/android.jar`，
用 JDK 11+ 编会把 `java.lang.invoke` 之类的类拉进来，d8 阶段报 `Invalid class` 或运行期 `NoSuchMethodError`。

**为什么 minSdk 29**：车机就是 29；`--min-sdk-version 29` 让 aapt2 不做旧版兼容回填，APK 更小也更快。

## 三、构建

```bash
cd ~/Desktop/DSH/仪表助理
./tools/build.sh overlay    # 只编主程序 com.byd.clusterlab
./tools/build.sh assist     # 只编面板  com.byd.clusterassist
./tools/build.sh all        # 两个都编
```

`build.sh` 内部顺序（了解即可，出问题去哪看）：

1. `aapt2 compile --dir res -o res.zip`
2. `aapt2 link` → `base.apk`（`-A assets` 只在目录存在时加）
3. `javac` 编 `src/**/*.java`（`-bootclasspath android.jar : shizuku 三个 classes.jar`）
4. `jar cf app.jar` → `d8 --min-api 29` → `classes.dex`
5. 把 dex 用 `zip` 塞进 `base.apk` → `zipalign -f 4` → `apksigner sign`
6. `apksigner verify --print-certs` 打印证书确认

产物落在 `clusterlab/build/clusterlab.apk` / `assist/build/assist.apk`，需要时手动拷到 `apk/`。

> `build.sh` 默认路径在本包里已经改好（`SHZ="$ROOT/src/shizuku"`、`KS="$ROOT/tools/clusterlab-debug.jks"`），
> 直接跑即可。原工程在 `~/Downloads/byd_probe/build.sh`，路径不一样，别混。

## 四、签名

| 项 | 值 |
|---|---|
| keystore | `tools/clusterlab-debug.jks`（原 `clusterlab/debug.jks` 的副本） |
| alias | `debug` |
| storepass / keypass | `android` |
| 证书 | `CN=debug` |
| SHA-1 | `2ae511b6db46ac07c4aaeb476ac72d366b84864b` |
| SHA-256 | `86ff7513c6c7fc2edd2a451a824cf485ad27db12a9dd5a29a43ee918025c4dcc` |
| 签名方案 | v1 + v2 + v3 |

**两个 APK 用同一个签名的原因**：assist 面板要读 overlay 的心跳文件、要用 Shizuku 拉 overlay；
虽然不共享进程，但同签名省掉一堆 `signature` 级权限的麻烦。升级时也只需 `adb install -r`。

## 五、安装与调试

```bash
ADB=~/Library/Android/sdk/platform-tools/adb

$ADB connect 192.168.46.1:5555
$ADB install -r apk/ClusterHUD-1.0-v2.apk
$ADB install -r apk/ClusterAssist-1.0.apk

# 第一次装完必须做的授权（否则全是空数据）
$ADB shell settings put secure enabled_accessibility_services com.byd.clusterlab/com.byd.clusterlab.CarAccess
$ADB shell settings put secure accessibility_enabled 1
$ADB shell cmd notification allow_listener com.byd.clusterlab/com.byd.clusterlab.MediaListener
```
